# 路线图

最后更新：2026-04-11

## v0.2（近期）

1. 为 `time_converter` 增加专用 UI 面板。
2. 增加插件配置持久化（`.data/config/plugins.json`）。
3. 补充插件层单元测试与注册契约测试。

## v0.3（中期）

1. 提供插件模板脚手架命令（创建目录、manifest、plugin 骨架）。
2. 增加日志轮转和保留策略。
3. 支持工具级权限确认中间层（高风险动作统一确认）。

## v1.0（长期）

1. 跨平台适配（Windows/macOS/Linux）能力矩阵。
2. 插件市场化分发约定（签名、版本与兼容策略）。
3. 全量 UI 元数据驱动，减少手写前端逻辑。
